# 经营罗盘 · 餐饮经营顾问站

一个纯静态网站：餐饮经营顾问的品牌首页 + 单店保本点速算器。
无框架、无外部依赖、无网络请求，可直接部署到 GitHub Pages。

线上地址：<https://2026wyz.github.io/jingying-luopan/>

## 页面

| 文件 | 作用 |
|------|------|
| `index.html` | 首页：顾问定位、服务内容、工作方法、工具入口 |
| `tool.html` | 功能页：保本点速算器（实时计算 + 小票 + 图表 + 敏感性表） |
| `assets/styles.css` | 全站样式（含响应式与打印样式） |
| `assets/app.js` | 计算、渲染、本地保存 |
| `assets/favicon.svg` | 站点图标 |

## 功能

- 输入 6 项数据：月固定成本、平均客单价、食材成本率、其他变动成本率、目标利润、月营业天数
- 实时输出：边际贡献率、月保本营业额、每日保本额、月/日保本客数、安全边际
- 三档目标：保本、满意利润、挑战目标（利润目标再提高 50%）
- 营业额—利润关系图（SVG，无图表库）
- 食材成本率 ±5 个点的敏感性表
- 一键打印小票（A4 排版）
- 输入自动保存在浏览器 localStorage，不上传服务器

## 计算口径

```
边际贡献率 = 1 − 食材成本率 − 其他变动成本率
保本营业额 = 月固定成本 ÷ 边际贡献率
保本客数   = 保本营业额 ÷ 平均客单价
```

未考虑税费、折旧口径、加盟分成、一次性投入等差异，结果仅作经营测算参考。

## 本地运行

直接双击 `index.html` 即可，无需构建、无需服务器。

本地更新后，同时推送两个分支：

```bash
git push origin main
git push origin main:gh-pages
```
